Nitefind: Location-Based Reccomendations

Nitefind is a location-based recommendations app built to help users quickly choose where to go out based on vibe and real-time venue details. The project includes extensive UX and UI work, highlighting research insights, persona development, user flows, and a polished dark-mode interface designed for fast, intuitive decisions.

View the Full Case Study

Research

I interviewed users to understand how they choose nightlife spots and why the process feels overwhelming. Key insights around decision fatigue and unreliable venue info shaped the foundation of the app.

Ideation

Using those insights, I created personas, defined Jobs-to-Be-Done, and mapped user flows focused on quick, low-friction decisions. This work established the core features and experience.

Wireframe

I developed low- and mid-fidelity wireframes to define layout and navigation. This step clarified structure and ensured the flows supported fast, intuitive discovery.

Design

I created a polished dark-mode interface with clean visuals, custom icons, and bold accents. The final design makes real-time venue discovery quick, clear, and visually expressive.
